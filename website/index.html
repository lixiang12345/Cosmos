Why Cosmos

从「聊天窗口」升级为「运行系统」

Cosmos 的一等对象不是消息，而是任务、运行、事件、产物和审批。个人 Agent 的增益一旦沉淀为组织的专家与自动化，就会随每一次交付复利。

异步执行Async by default

提交目标后就可以离开。专家在云端沙箱里持续推进，需要人做判断时通过审批与通知把你召回，而不是让你盯着终端等结果。

专家复用Reusable Experts

把团队规范、工具权限、触发条件和执行步骤固化为可复用的专家，而不是每个人反复调提示词。一名工程师打磨的工作流，全组织开箱即用。

跨工具闭环Closed loop

从 Slack 或 GitHub 发起，经代码修改、检查、PR、Review 反馈到合并建议，状态与结果回写原线程，全程不丢上下文、不换工具。

可见、可控、可审计Governed

每次计划、工具调用、代码差异、审批和外部写操作都有状态、依据与审计记录。低风险步骤自动推进，高风险步骤必须说明影响并等待授权。

Building Blocks

七个一等公民，组成一台交付操作系统

Cosmos 不是单一 Agent，也不是纯工作流引擎。专家、环境、会话、自动化、文件、Worker 与 Space 各自独立、可配置、可共享，组合出覆盖完整研发生命周期的编排系统。

Flagship Workflow

代码审查流水线：专用小队 + 人在判断点

一条 PR 打开后，风险分析专家先分流：低风险自动通过；高风险交给深度审查、结对审查与验证专家并行处理，记忆管理专家把结论沉淀为组织记忆。

  • 人不再逐行读每个 PR。人只在架构、产品、安全与发布判断点出现。
  • 每个专家专注一个意图。审查与写码的优化目标不同，一个大提示词做不好两件事。
  • 结论带证据。行级意见附带测试结果与运行时证据，而不是空泛评价。

Safe by Default

默认安全：Nothing fires until you say so

规模化采用 Agent 的前提，是安全团队敢放行。Cosmos 把安全边界做成产品底色，而不是恐吓弹窗。

触发器默认关闭

新自动化部署即处于 disarmed 状态：先试跑一次、确认行为，再启用。暂停不删除配置，事件过滤在开会话之前执行。

高风险动作过审批门

创建 PR、发布评论等外部写操作必须展示影响范围、证据与回滚方式，等待人工批准、要求修改或拒绝，并留下决策记录。

Secret 只存引用

密钥密文写入后不可读回，任何查询只返回末四位掩码；Provider 凭据由服务端注入，永不进入浏览器构建产物。

数据库层强制隔离

全部租户表启用 PostgreSQL FORCE RLS；API 与 Worker 使用无登录运行角色，不持有表所有权，配置不符即拒绝启动。

OIDC + PKCE 身份

生产 Web 使用授权码 + PKCE，access token 仅驻留内存，生命周期硬上限 300 秒；401、过期与登出即刻清除身份。

全链路审计

外部事件、用户操作、Agent 写操作、审批与结果全部落入 append-only 审计流，可按类型、来源、状态与时间检索。

Models & Context

受控模型目录，结构化上下文

不锁死单一供应商，也不放任随意接入：五个模型经由统一目录治理，按模型族选择凭据。接入 Context Engine 后，专家用更少的 token 拿到同等质量的代码库上下文——检索经过 Space 与仓库绑定鉴权，密钥保持在服务端。

Run Anywhere

五分钟起本地运行时，生产路径有据可循

一条命令拉起 PostgreSQL、API、Worker 与 Web 的完整 Docker Compose 运行时；生产部署提供独立迁移作业、健康探针、备份恢复与可观测性 Runbook。
